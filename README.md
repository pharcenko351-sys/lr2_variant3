# ЛР №2, варіант 3 «Гуртожиток»
Виконувала Харченко Поліна К-28

Програма яка читає XML зі списком студентів, які живуть у гуртожитку, шукає в ньому і перетворює знайдене в HTML за XSL-файлом.

Пошук можна виконати трьома способами: через SAX, DOM або LINQ to XML. Спосіб обирається у списку, а за кожним стоїть окрема стратегія, тому результат у всіх трьох однаковий.

## Що вміє програма

- Завантажує XML і бере з нього значення для списків: факультет, кафедра, курс, гуртожиток.
- Шукає за цими полями та за ключовим словом. Слово шукається в ПІП, телефоні, номері кімнати й корпусі.
- Кнопка «Обрати XSL» читає таблицю стилів.
- Кнопка «Трансформувати в HTML» перетворює тільки те, що знайдено. Якщо вибрати 2 курс, у HTML будуть лише студенти 2 курсу. Файл `<назва xml>_result.html` з'являється поруч з XML і відкривається в браузері.
- Clear очищає фільтри й результати.
- І кнопка «Вийти», і хрестик вікна питають, чи справді закрити програму.


## Формат XML

```xml
<dormitory>
  <student FullName="Коваленко Олена Петрівна" Faculty="..." Department="..." Course="2" Phone="+380501112233">
    <residence Building="Гуртожиток №1" Room="214" StartDate="2023-09-01" />
  </student>
</dormitory>
```

У студента може не бути `Phone`, тож атрибутів 4 або 5. У `residence` може не бути `EndDate`, це означає, що студент живе там досі. Рівнів три: `dormitory`, `student`, `residence`.

## Запуск

У Rider виберіть конфігурацію `DormitoryXml` і натисніть Run.

З терміналу:

```bash
cd DormitoryXml
dotnet run -f net10.0-windows10.0.19041.0
```
## Як перевірити

1. «Завантажити XML» і вибрати `dormitory.xml`.
2. Поставити фільтри, вибрати спосіб аналізу, натиснути «Знайти».
3. «Обрати XSL» і вибрати `dormitory.xsl`.
4. «Трансформувати в HTML». У браузері має відкритися таблиця зі знайденими студентами.

Що має вийти на `dormitory.xml`:

| Фільтри | Знайдено |
|---|---|
| нічого не задано | 10 |
| факультет «Економічний факультет» | 3 |
| курс 2 і Гуртожиток №1 | 1 (Коваленко) |
| курс 3 і Гуртожиток №2 | 1 (Шевченко) |
| ключове слово `мар'яна` | 1 (Бондар) |
